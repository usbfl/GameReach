# 0.9.0 更新与交接

- 新研究协议在 `backend/app/tags/`，新UI走 `/api/tag-research`；旧DNA协议兼容旧客户端和历史。
- 研究输入+主动附加的确认卡片先由LLM解释，再发目录召回。附件是ID/版本校验后的文本快照，不覆盖输入。
- 64项标签，15类体验，37条来源；词义、同义词、边界和Steam/GOG/Epic/itch映射可审阅、重建。
- 不再给新任务套旧0–4评分、至少3项机制/3条引用/20条阅读或全维度已知门槛。
- Steam完整正文不截断，完整阅读账本、逐字证据和独立语义核验；作者/正文去重后统计支持与反对。
- 初始确定性排序综合匹配、覆盖、支持量和总体口碑。缺口保留，局部重排不联网、不改历史。
- 评论以完整文档为单位受32000字符/游戏上限限制；长文待处理。当前没有GOG/itch等全文运行时适配器。
- 测试：完整后端208项通过；最终修改后标签12项针对性回归通过；构建、格式单测、本地启动+HTTP烟测通过。浏览器测试因Chromium下载失败阻塞。无本版真实密钥端到端验收。

可重建文件：`python scripts/build_tag_vocabulary.py` 生成词典和来源登记；`python scripts/build_tag_fixtures.py` 生成合成评论（不是从旧机制分数反推）。新增词条需要真实来源、混淆边界与平台映射审阅，不能只增加别名命中率。

后续优先做：真实模型逐项人工标注集；原生平台标签召回与其他站点合规全文适配；长文完整处理；对照玩家偏好校准排序。不得把本轮合成测试当成真实推荐质量。
