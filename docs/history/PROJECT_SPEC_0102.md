# 当前产品边界 · 0.10.2

目标：从玩家真实表达中理解兴趣，用可追溯评价找到值得进一步了解的游戏。

## 当前推荐协议

新探索入口使用玩家体验标签，先LLM解释输入及主动附加卡片，再进行目录召回、完整评价提取、独立核验和确定性排序。移除新流程的旧DNA机制门槛、0–4偏好表单和全维度覆盖要求。普通偏好未知不是失败；没有已核验匹配不能靠热门程度变成推荐。

64个种子标签与映射见 `app/tags/vocabulary.json`（相对backend）及 `docs/research/`。平台标签只做召回，不是体验证据。现阶段通过IGDB目录代理映射；Steam是运行时完整评价接口。不得将人工研究过的论坛误称已接入。

自动模式逐款完成获取、提取和核验，再调查下一款；单款模型失败隔离，已核验成果在预算耗尽时保留。人工模式保留一次审阅节点。未获标签证据的候选展示紧凑诊断列表，不显示排序分和伪造的 0% 指标。默认每批最多 4 篇完整评价、16,000 字符；最多 3 批，按主要需求缺口追加。可附加一份完整商店介绍作为核心玩法来源，不能作为玩家体验证据。未纳入正文单独计数。

只以获得有效结构化提取结果的完整清洗正文计完成分析量；提交但失败的调用另记 model_requests，并记录版本哈希与完整字符范围。超长文档待处理，不截取局部当全文。支持与反对各自保留；标签缺失不代表体验不存在。作者/正文去重，场景限定不泛化，来源过期/撤销不能参与新重排。

初始排序权重：匹配×覆盖60%，独立支持数量25%，总体平台口碑15%；数量每标签3位饱和。缺失口碑显示未知，用中性排序先验。权重需后续校准。没有强制最少20条/3条/3项机制门槛。用户本次明确的必要要求仅在有可核验反证时排除，未知时待确认。语言、平台与预算作为可选事实范围保留。

## 兴趣卡片与输入

分类是卡片标题，内容固定为“相关游戏”和“概括”；每类3–7款不同游戏，先确定成员再总结共同特征。不足3款或资料不足时保留待归类项；超过7款均衡拆分。同一轮同款游戏只归一类，游戏库、关注和反馈中的重复游戏去重。用户可编辑概括、确认、删除；已确认旧文字卡片保留并提示重新整理关联游戏。时长/收藏/关注仅为线索，不自动证明喜好。用户主动附加最多6张已确认卡片，研究保存ID与版本快照；当前输入优先。附件不能覆盖输入，未附加历史不能静默注入研究。标题用于分类，不单独产生筛选要求。

## 基础设施与兼容

保留持久化Engine、SSE、预算/重试/缓存、数据与模型隔离、人工审阅、精确引用、导出、个人库和兴趣清单。人类研究节点可补充待核验笔记，模型辅助提取；人工核验仅接受明确勾选的主张。未选项不会通过。

新UI调用 `/api/tag-research`；旧DNA接口和历史保留兼容，不再主导新入口。浏览、查看来源与本地重排不暗中联网；改变需求需要新研究。没有新增数据库表，升级保留用户配置、数据和历史。

不扩展自动购买、对外发布、社区账号、公告订阅、游戏代理或无验证收益的向量基础设施。不得修改/删除用户密钥，不得用合成资料替代真实调用失败。

## 0.10.0 证据与数量

均衡档默认500条目录记录分支分页扫描，当前输入优先排序后保留80款目录候选，从30款初筛名单先调查最多5款。未达目标则逐款递补，均衡总上限为max(5,目标数×2)，且不超过环境上限20。快速档最多150条、20款初筛、3款调查、每款1批；扩大档80款初筛、最多20款调查。所有档位仍受现有工具/外部请求/时间/模型预算约束。目标1–10款，证据与预算不足不凑数。玩法介绍、支持理由、取舍或未知声明、口碑与完整来源共同形成卡片；只满足避开项而无想要玩法证据不能计为精选。语义标签只允许本次 intents；单条结构错误不吞整批，超量主张有界保留并记录。未知与上下文限定继续保留。旧报告是不可变历史；升级后需发起新研究，尚无旧任务补跑按钮。

游戏库草稿与探索页使用相同的逐款来源分类协议。相关游戏名称由服务器从实际来源补齐，不能由模型虚构；附加卡片保存完整成员快照，但偏好提取仅依据概括text，游戏名不直接变成筛选关键词。卡片生成没有资料时不发起模型调用；游戏库分析的在线匹配和卡片整理共用一次预算。

## 0.10.2 本地预算策略

来源目录/详情缓存默认6小时，评价30分钟；不缓存部分来源失败。兴趣分组和已核验全文批次缓存默认24小时，每个缓存命名空间最多200项。缓存到期、来源撤销或更新、数据集/模型/协议/作用域变化会失效。复用批次需要相同完整需求解释与正文身份，重新生成任务内主张并重查引用有效性；仍保留支持和驳回意见。人工核验流程不复用自动核验结果。空/失败/不完整核验不缓存。

兴趣卡片按来源、游戏资料和语境指纹复用，稳定分组保留，只整理剩余变化游戏。不足3款保留待归类；可勾选全部重新分组。旧卡片与旧报告不被重写。

追加全文仅针对主要需求/明确要求未知或冲突、玩法介绍/偏好证据缺口和独立观点平衡。已有反对/近期分层保持；正文与作者去重；平台口碑未知不能靠多读评价修补。没有相关可读全文、追加无新增证据、达到档位上限或需要为下一款保留预算时停止。词匹配只决定读哪些完整评价，不能产生匹配结论。JSON/Markdown/UI记录策略、缓存计数和停止原因。模型路由、单价和调用协议保持不变；本版不执行真实付费验证。
