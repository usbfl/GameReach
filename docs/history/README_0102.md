从当前输入与主动附加的兴趣卡片出发，先理解需求标签，再寻找游戏与完整玩家评价。新版探索入口替代旧版机制硬门槛、0–4 DNA 表单和“所有关注项已知才推荐”的规则。

## 启动

先打开 `START_HERE.html`。Python 3.11+；Windows 双击 `Start_GameReach.bat`；macOS / Linux：

```bash
bash scripts/run_demo.sh
```

保留终端，访问 <http://127.0.0.1:8000>。首次安装依赖需要网络；包内有构建后的前端和字体，直接体验不需要 Node.js。默认24款虚构目录，其中7款有本版人工编写的完整评价用于标签演示，其他候选允许显示待调查。

## 使用路径

1. 导入个人游戏资料，结合收藏、分类、明确反馈生成卡片。分类是标题，概括是正文；先编辑和确认。
2. 在研究输入中描述当下需求，可附加最多6张卡片。附件不覆盖输入；没附加的历史卡片不自动进入本次研究。
3. 选择商店和运行平台，开始探索。真实模式先调用LLM得到有输入原句依据的标签、意愿方向和场景，再做候选搜索。
4. 查看匹配度、覆盖度、独立支持/反对评价、平台口碑；打开证据可阅读完整清洗正文、来源和定位。
5. 调整标签重要度可在固定证据上本地重排；结果导出保持原报告快照。改变需求或范围请开始新任务。

## 本轮研究与改动

- **64个体验标签、37条来源记录**：23个可读取正文的社区/评价页面，1条仅作为线索的搜索记录，13条官方说明/平台目录。覆盖 Steam、Reddit、GOG、itch.io、机核、TapTap，并核对 Epic 等平台分类规则。页数不是独立玩家样本数，不是全网词频研究。
- 词典包含定义、中英近义表达、易混淆含义、来源和四商店映射。区分练Boss/刷装备、死亡损失/跑尸/寻路、单人/合作/语音负担、持续恐惧/跳吓等。
- 原生商店标签映射供召回使用；当前运行时经 IGDB 类型、关键词和商店链接做代理。完整评价接口目前接入 Steam。论坛研究不等于全部论坛已接入运行时。
- 评论正文不再被30,000字符静默截断。每款按好评/差评/近期取样，选取完整正文送入模型；超出当前16,000字符批次的文档延期并明确计数，不用摘句冒充全文。
- 独立核验后才计标签匹配。否定、转折、讽刺、比较对象、难度、版本和阶段需要保留。统计按作者与标准化重复正文去重。
- 排序使用60%匹配×覆盖、25%独立支持数量、15%口碑下界的初始权重。不是客观质量分或推荐概率，后续需真实用户偏好实验校准。平台总体口碑与抽样评价比例分开。

详细研究：[方法、结论与设计](docs/research/RESEARCH_AND_DESIGN.md) · [完整词典/映射/来源](docs/research/PLAYER_TAG_DICTIONARY.md) · [测试记录](docs/TEST_REPORT.md)。

## 真实模式

复制 `.env.example` 为 `.env`；已有配置保留并编辑。设置 `DATA_MODE=live`、`LLM_MODE=live`、`IGDB_CLIENT_ID`、`IGDB_CLIENT_SECRET`、`LLM_BASE_URL`、`LLM_API_KEY`、`LLM_MODEL`，然后重启。导入 Steam 个人库才另需 `STEAM_WEB_API_KEY`。操作说明见 [CONNECTIONS.md](docs/CONNECTIONS.md)。真实来源或真实模型失败不会切换到演示。

默认扫描最多500条目录记录（含多查询重复），去重后按当前输入优先保留80款，调查上限20款。每款获取最多36篇完整评论，每批最多4篇及16,000字符，缺少主要证据时预算内追加，最多3批；不会截断长评冒充全文。界面选择期望1–10款，未达到时列明实际数量和原因。原有25次外部请求/180秒预算继续生效；更多数量可参考 `.env.tag-budget.example`，不会自动扩大付费预算。平台口碑、正反证据和未知项均保留；普通偏好未知不等于满足，只有避开项而没有任何想要玩法的支持时列为待确认。

## 升级与兼容

停旧服务并备份数据库，在新目录解压，再复制原 `.env` 与 `data/gamereach.db`。不要把旧源码整体覆盖回来。本版无新增表，卡片、游戏资料和旧报告保留。新UI使用 `POST /api/tag-research`；旧 `/api/research` 的默认DNA协议及旧报告只作兼容。也可向 `/api/research` 显式传 `recommendation_mode: "player_tags"`。

`MIN_REVIEWS_FOR_RECOMMENDATION`、`MIN_CITED_REVIEWS`、`MIN_KNOWN_MECHANICS` 仅影响旧DNA协议，不再影响新入口。旧评估脚本仍是旧协议测试，不能当成本版推荐质量评测。
