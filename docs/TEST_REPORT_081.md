## 已复现并纠正的问题

1. 下载评论数量不等于送给模型的阅读量，之前未调查的目录候选也进入结果。
2. 少数长差评占据检索片段；默认每页20条、经验输出预算过少。
3. 任意“标准爬塔”等scope名使已经通过的机制无法在默认画像展示。
4. 核验标准过度要求官方证据；同时提取模型常把quote外内容塞进一个命题。现保留逐项核验，机制使用单一词表命题；不合格体验最多局部修订一次。
5. IGDB发售状态缺失；Steam商店可以核对，但未满足发售限制的候选应立即停止后续采集。
6. “牌组构筑”别名与 deck-building / deck building 拼写遗漏，空评价量目录排序靠前，浪费有限调查预算。
