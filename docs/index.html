GAMEREACH / v0.11.0

把“想怎么玩”，
变成有依据的游戏推荐。

从你的游戏资料整理兴趣，理解这次的玩法要求，再对照游戏介绍与玩家评论，给出匹配理由、取舍和可核对的出处。

查看验收报告 →浏览完整源码 ↗

这是项目展示与报告页。完整应用需启动 Python / FastAPI 服务；默认使用合成游戏数据与 mock 模型，不调用真实付费服务。

一条围绕当前需求的研究路径

01 / 理解兴趣

同一游戏，可以代表不同兴趣

从游戏库、收藏、反馈和游玩线索生成可编辑的主题卡片；允许主题交叉，不把游玩时长直接等同于喜欢。

02 / 确认条件

你决定哪些偏好不能妥协

兴趣卡片与本次输入转为玩法标签、重要度及软硬条件；用户可以修改并确认，当前明确要求优先。

03 / 查证推荐

只为关心的玩法继续找依据

目录召回候选，按预算补查关键评论；保留反证与未知项，提供引用位置，并复用有效缓存。

在本地体验

需要 Python 3.11+。项目已包含构建后的前端；首次安装 Python 依赖需要网络。

git clone https://github.com/usbfl/GameReach.git
cd GameReach
# Linux / macOS
DATA_MODE=fixtures LLM_MODE=mock bash scripts/run_demo.sh

Windows：在项目根目录执行 .\scripts\run_demo.ps1。服务启动后访问 http://127.0.0.1:8000。
